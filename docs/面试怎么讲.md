# 这个项目怎么讲给面试官

> 目标不是显得很厉害,而是**显得「懂」且「诚实」**。实习岗更看重基础和学习态度。

---

## 一句话介绍(背下来)

> 「我做了个 AI 笔记的小项目:Spring Boot 后端,能存笔记,并且调用 DeepSeek 的接口给笔记自动生成一句总结。核心是搞懂了『调用大模型本质上就是一次 HTTP 请求』这件事。」

---

## 3 个最可能被追问的点 + 怎么答

### Q1:「AI 是怎么调的?」

> 「用 JDK 自带的 HttpClient 发一个 POST 请求到 DeepSeek 的接口,请求体是 JSON,带上 model 和 messages,请求头里放 `Authorization: Bearer <key>` 做鉴权。返回的 JSON 里 `choices[0].message.content` 就是 AI 的回答,再用 Jackson 解析出来。」

(能说到「HTTP + JSON + 鉴权头 + 解析」这几个词,就够了。)

### Q2:「为什么用 JDK 自带的 HttpClient,不用现成的 SDK?」

> 「因为想先理解底层:所谓调 AI 就是一次 HTTP 请求,用 HttpClient 能让我看清每一步(拼 JSON、带鉴权头、解析响应)。理解了底层,以后换成 OpenAI SDK 或者别的家,就只是换个工具而已。」

(这句很加分,显得你是为了学习而选,不是不会用别的。)

### Q3:「数据存在哪?为什么没用数据库?」

> 「笔记先存内存的 List 里,是为了快速跑通全流程。我是把 Controller / Service 分层拆开的,后面要持久化,只要改 Service 这一层、把 List 换成 MyBatis 访问 MySQL 就行,Controller 不用动。」

(主动提到「分层让替换容易」,展示你理解了架构的好处。)

---

## 加分项(会了就说,不会别硬撑)

- 说得出「分层:Controller 收请求 → Service 干业务 → Model 是数据」。
- 说得出「依赖注入:Spring 帮我把 Service new 好塞进来,我用的是构造器注入」。
- 说得出「200/401/404/500 状态码分别是啥」。

---

## 诚实表达「还在学」

如果被问到不会的(比如 MySQL 优化、Redis 缓存、并发),可以这样说:

> 「这块我目前接触得还比较浅,苍穹外卖里用到过但还没吃透,这是我在实习里特别想补的方向。」

比硬编一个错误答案好得多。**实习岗看的是潜力和态度,不是背题。**
